# Redux Toolkit Compiler
Este repositório compila o pdf.js para facilitar a importação do mesmo em projetos simples.

## Pré-requisitos
Certifique-se de instalar as versões do Node e NPM compatíveis:
Node 18.17.0 ou superior
NPM 10.8.3 ou superior
NVM (para windows) 1.1.9 ou superior

## Como Usar
Você pode utilizar apenas baixando os arquivos da pasta dist ou compilar por você mesmo seguindo os passos abaixo:

### 1. Clone o repositório
```bash
git clone https://github.com/luislobo9b/pdf.js-compiler.git
cd pdf.js-compiler
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Compile o projeto
Rode o comando:
```bash
npm run build
```
